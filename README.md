手机号字典生成器

一款功能强大的交互式手机号前7位字典生成工具，支持按省份、城市、运营商精确筛选，全量/随机两种生成模式。



📌 项目简介

PhoneDict 是一款专为网络安全测试、渗透测试、安全研究而设计的手机号段字典生成工具。它内置了全国各省份、城市、地区的电话区号编码，以及中国移动、联通、电信、广电、虚拟运营商的号段数据，能够根据用户需求精确生成前7位手机号前缀，方便后续扩展为完整的11位手机号码字典。

适用场景：

· 渗透测试中的社会工程学（Social Engineering）字典生成
· 安全研究中的手机号格式验证、号段分布分析
· 网络安全演练中的测试数据准备



✨ 功能特性

功能模块 说明
省份/城市选择 支持全国34个省级行政区，覆盖所有地级市及部分县级市
运营商号段筛选 支持中国移动、联通、电信、广电、虚拟运营商，可多选
地区编码自动关联 每个城市自动关联其电话区号（如北京=0100），精准定位号段
全量生成模式 生成所有可能的前缀组合，适用于穷举场景
随机抽样模式 指定数量，均匀分布随机抽取，适用于快速构建测试集
进度条可视化 集成 tqdm 进度条，实时显示生成进度
自动安装依赖 首次运行时自动安装 tqdm，无需手动配置

📦 输出文件

生成的文件默认保存在当前目录，文件名格式：

模式 文件名格式
全量生成 phone_dict_full_20260828_143022.txt
随机生成 phone_dict_random_20260828_143022.txt

文件内容：每行一个7位手机号前缀（不含后4位），例如：

```text
1300100
1300101
1300102
...
```

💡 扩展为11位手机号：可通过脚本或工具在每个前缀后追加 0000 至 9999，即可生成完整的11位手机号。

🛠️ 自定义扩展

修改/添加城市编码

编辑 CITY_CODES 字典，按以下格式添加：

```python
CITY_CODES = {
    "新省份": {
        "新城市": "区号",
        "新城市2": "区号"
    }
}
```

修改/添加运营商号段

编辑 OPERATORS 字典：

```python
OPERATORS = {
    "新运营商": ["新号段1", "新号段2"],
}
```

批量无交互模式（静默运行）

如需在脚本中直接调用，可修改 main() 函数，或提取 generate_full() 和 generate_random() 函数独立使用。
